# 会议 UI 模块配置

桌面前端统一在 [`frontend/src/config/meeting-ui.json`](../frontend/src/config/meeting-ui.json) 配置会议模块。配置属于客户端构建的一部分，不放在组件内部、个人设置或后端地址配置中。默认全部开启，保留现有行为。

例如只保留语音和聊天，将 `video`、`screenShare` 设为 `false`：

```json
{
  "audio": true,
  "video": false,
  "chat": true,
  "screenShare": false,
  "members": true,
  "handRaise": true,
  "recording": true,
  "settings": true
}
```

| 字段 | 关闭后的行为 |
| --- | --- |
| `audio` | 隐藏入会麦克风选项、语音入口、设备菜单、麦克风状态及全体静音；阻止自动开麦、连接电脑音频和本地远端音频播放；同时关闭会议录制。 |
| `video` | 隐藏入会摄像头选项及工具栏摄像头；阻止自动开启摄像头；网格保留成员头像，不播放摄像头画面。 |
| `chat` | 隐藏会议聊天按钮、侧栏聊天页签和会议成员 IM 资料入口；不初始化会议聊天会话，不加载/发送会议消息或附件。应用的独立消息页不受影响。 |
| `screenShare` | 隐藏共享按钮和共享状态/画面；不绑定共享会话、不处理共享信令或启动选屏。与摄像头开关独立。 |
| `members` | 隐藏工具栏成员按钮及侧栏成员页签；参会成员网格和基本会议状态仍保留。 |
| `handRaise` | 隐藏更多菜单举手项和举手标记；阻止发起举手。 |
| `recording` | 隐藏录制状态条；本客户端不创建会议音频录制器。录制依赖 `audio=true`。 |
| `settings` | 隐藏更多菜单会议设置入口和弹窗；本客户端不发起会议设置更新。 |

修改后，开发版退出并重新加入会议以应用整个会话的配置；部署版重新构建和发布。全关仍可入会、查看成员头像、查看会议信息、返回首页、离会及结束会议。关闭成员面板后没有等候室审批入口；有等候室的主持人客户端应保留 `members=true`。

[`meeting-ui.ts`](../frontend/src/config/meeting-ui.ts) 提供只读类型配置，类型检查会检查字段完整性和布尔类型，并处理语音与录制依赖。入会意图即使残留 `micOn=true` / `camOn=true`，也必须经过配置过滤。

这些配置决定当前客户端展示与本地功能启动，不代替服务端权限，也不会禁止其他客户端发布音视频、聊天或录制。若后续需要管理员在线配置、按租户/会议下发，应由服务端提供能力策略，再在此统一配置层合并，并继续由服务端校验；当前不新增后台管理或运行时配置接口。Flutter 移动端使用自身配置，不受本文件控制。
