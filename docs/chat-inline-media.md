# 聊天图片与视频直接展示

## 需求与范围

图片消息（包括以file上传的图片）进入可见区域后直接显示缩略图，点击放大；视频显示首帧和播放按钮，点击在气泡内播放，可放大并从原播放位置查看。去掉图片、视频卡片中重复的“预览 / 播放”，下载改为图标，保留可访问名称。语音、文本与普通文件保留已有打开方式。

浏览器的屏幕采集提示条，属于浏览器界面，应用页面不能通过CSS替换或隐藏；可使用浏览器自带的“隐藏”。系统采集路径由平台控制。应用已有共享舞台状态、停止共享和跨页返回入口继续保留。

## 实现约束

- 使用现有SDK鉴权下载、受限本地协议与30MB上限，不把原始OSS地址直接交给img/video，不绕过ACL。
- IntersectionObserver只在媒体进入可见区域时加载；失败不自动循环，保留错误、重试、取消和下载。视频不自动播放声音。
- 图片放大关闭后仍需用于气泡展示，因此缓存保留到消息卸载；离开聊天、撤回或消息替换时终止下载、停止视频并释放缓存。非行内附件关闭预览后按原行为释放缓存。
- 桌面、窄窗口都限制媒体宽度，图片contain避免截掉内容，视频小播放器使用16:9容器，文件名省略但title可查看。
