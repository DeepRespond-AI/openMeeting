# 隐私与可选使用统计

会议、录音、转写、聊天与模型服务的数据流见[系统架构](architecture.md)。自部署不代表所有能力均离线：配置的 IM/RTC、短信、对象存储、云端 ASR 和 LLM 会处理对应请求，应由部署方确认服务区域和数据政策。

桌面使用统计默认关闭。开源构建不内置维护者或上游的统计项目；未提供 `OPENMEETING_ANALYTICS_KEY` 时统计不可用，设置页显示当前部署未启用统计。即使部署方配置统计项目，也需要用户主动开启。

维护者可在原生编译前设置自己的 `OPENMEETING_ANALYTICS_KEY`，以及可选的 `OPENMEETING_ANALYTICS_HOST`（HTTPS 主机，默认 PostHog US 接口）。不设置 key 是关闭统计的标准方式；变量变化后重新构建，不能只修改已安装应用旁的文件。自有主机地址会用于 SDK 实际发送，不能仅在说明中替换地址。

开启后会产生持续的匿名用户/会话标识、应用与系统版本、操作事件、处理时长和诊断数据；这些标识可关联同一安装的使用行为，不应描述为完全不可关联。会议标题、名称、文件名与路径等敏感字段有过滤，但新事件仍需审查，避免将业务内容加入任意属性。公开 Issue 中不应粘贴令牌、录音、转写或带签名的下载链接。

部署者应根据自己的功能配置向用户说明处理方、用途和保留时间。服务端备份和对象保留见[运维指南](../server/OPERATIONS.md)；安全问题见[安全报告](../SECURITY.md)。
