## 1. 背景与目标

V2 对电脑端做两件事：

1. **视觉改版**：从浅色企业蓝切换为深色 Aurora Dark（深空夜幕画布、玻璃拟态卡片、靛蓝→蓝→青品牌渐变、发光阴影）。
2. **功能扩展**：由「录音转写 + AI 纪要」工具升级为会议工作台，新增 **加入会议 / 快速会议 / 预定会议 / 实时会议房间** 四类能力，首页改为快捷入口 + 今日会议 + 最近纪要的导航枢纽。

## 3. 功能需求

### 3.1 全局框架
- 左侧 64px 深色窄导航轨道：Logo、首页/会议/录制/设置（图标+小字，选中态品牌渐变发光块），底部渐变头像 + 账户菜单（账号设置、退出登录带确认弹窗）。
- 侧边栏不显示会议列表、服务器状态 footer；语言切换位于设置页。
- 全局 Toast（右下角）；路由切换清理弹窗/菜单/视图级定时器。

### 3.2 首页
- 时段问候语（夜深了/早上好/…/晚上好）+ 大号日期与星期。
- 四张快捷入口卡：加入会议、快速会议（立即生成 6 位会议号进房）、预定会议（弹窗）、录音转写（跳录制页）。
- 今日会议：按日期过滤预定会议，状态徽章（进行中=红色脉冲 / 即将开始 / 已结束），未结束的显示「加入」按钮。
- 最近会议纪要：最近 5 条，含来源标签（录音转写/导入音频），点击进详情。
- 空态插画 + 引导文案；入场逐层上浮动画。

### 3.3 会议列表
- 标题 + 转写内容全文搜索，命中转写时展示片段与高亮。
- 列表/卡片双视图切换，选择持久化（localStorage → 实现为用户偏好）。
- 会议计数徽章；行级更多菜单：重命名、删除（确认弹窗）。

### 3.4 会议详情
- 三个标签页：会议信息（可点击标题重命名、元信息、播放器）、转写（分段+说话人）、AI 总结（富文本）。
- 会议级操作：重命名、删除、复制、导出、重新转写。
- 模拟播放器 → 对接真实录音播放（现有能力）。

### 3.5 录制页
- 设备（麦克风/系统音频）与转写语言选择。
- 开始/暂停/停止；实时转写段落流式追加；波形动画；录制计时。
- 停止后保存为会议记录（写入现有会议数据链路），可从会议列表查看。

### 3.6 预定会议（弹窗）
- 字段：会议主题、开始时间（自定义日期组件：月份切换 + 今天/明天/后天快捷 + 时/分双列选择）、时长（30/60/90 分钟 + 自定义）、入会密码开关（开启显示密码输入）、提醒开关。
- 提交生成 6 位会议号，写入预定列表（首页「今日会议」消费）。

### 3.7 加入会议（弹窗）
- 6 位会议号分段输入（2 段 × 3 位，自动跳格、退格回跳、支持粘贴）+ 昵称 + 麦克风/摄像头预开关。
- 任意合法 6 位号即可发起进房请求。

### 3.8 会议房间（全屏沉浸）
- 顶部栏：会议主题、可点击会议号（展开「会议信息/分享入会」卡片：会议号、入会链接、密码状态、复制邀请信息）、加密角标、计时器。
- 中央视频网格：2~6 人瓦片（头像占位 + 姓名 + 麦克风状态），悬停成员操作菜单，双击切换大画面/宫格。
- 底部工具栏：麦克风/摄像头/共享屏幕/成员/更多/离开会议。
- 右侧滑出成员面板（列表 + 全员静音）；会中聊天面板（文本 + 文件）。
- 离开确认。

### 3.9 设置
- 五个分类：账号（昵称修改、手机号）、通用（语言、外观相关偏好）、录音（默认设备、转写语言、自动总结等现有偏好迁移）、实验功能、关于（版本、更新）。

## 4. 数据与依赖（原型 → 真实实现）

| 原型 mock | 真实实现要求 |
|---|---|
| `DB.MEETINGS`（localStorage） | 沿用现有 Tauri/服务端会议存储与同步 |
| `DB.SCHEDULED`（localStorage） | 需新增预定会议存储（服务端或本地+同步，待定，见 §6） |
| `DB.genCode()` 6 位随机号 | 需后端会议号分配与唯一性校验 |
| 房间模拟参会者/聊天/共享 | 需实时音视频（WebRTC/SFU）、信令、聊天与文件通道 |
| `USER` 硬编码 | 沿用现有登录态（手机号 + 验证码） |

## 5. 与现有实现的差距分析

| 能力 | 现状 | 差距 |
|---|---|---|
| 深色主题与玻璃拟态 | 浅色主题，无 | 全局 token、globals.css、tailwind.config、组件主题重构 |
| 导航外壳 | 白色宽侧边栏（含会议列表/footer） | 重写为 64px 深色导航轨道 + 账户菜单 |
| 实时会议（房间/音视频/成员/聊天/共享） | 无 | **全新能力**：前端 + Tauri + 服务端 + SFU，工作量最大 |
| 会议号体系（加入/预定/分享/密码） | 无 | 全新，依赖后端 |
| 预定会议与今日会议 | 无 | 全新，含日期时间选择组件 |
| 录制独立页 | 录音流程内嵌 | 交互重组，复用现有采集/转写链路 |
| 列表/卡片双视图、内容搜索 | 仅列表、标题搜索 | 前端增强（服务端搜索需评估） |

## 6. 分期建议与待决问题

**分期建议**
- **P0（纯前端，可先行）**：Aurora Dark 主题 token 落地、导航外壳、首页、会议列表/详情/录制/设置深色改版。
- **P1（依赖后端）**：预定会议、加入会议、会议房间、会议号/密码/邀请分享。
- **P1 前置条件**：确定实时音视频技术选型（自建 SFU vs 云服务）与预定会议数据归属（服务端 vs 本地）。

**待决问题**
1. 会议房间是否为 V2 硬性交付？若是，WebRTC/SFU 选型、并发规模、加密要求需立项评估。
2. 入会密码、加密角标的真实语义（传输加密标识 vs 会议密码）需产品确认。
3. 预定会议的「提醒」如何触达（系统通知/应用内/推送）。
4. 转写内容全文搜索是否需要服务端接口支持（数据量大时前端过滤不可行）。
5. 移动端（Flutter）是否同步 V2 深色改版，时间点如何对齐。

## 7. 验收标准

- 所有页面符合 [UI_design.md](UI_design.md) V2 规范：无浅色残留、无裸 hex/gray-xxx/blue-xxx、全部文案走 i18n 双语。
- 路由行为与原型一致：房间页隐藏导航栏、非法会议号回首页、详情页无效 id 回列表。
- 现有功能（录音转写、纪要生成、播放、导出、设置）在深色改版后回归通过。
