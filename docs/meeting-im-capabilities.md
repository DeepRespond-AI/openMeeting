# 会议 IM 通知策略与平台边界

本页维护业务通知、桌面提醒筛选及平台待补齐项。会中群授权、消息/文件生命周期只维护在[会议聊天](meeting-im-chat.md)，工作台页面及统计适配见[IM 工作台](meeting-im-workbench.md)，当前整体完成范围见[功能状态](feature-status.md)。

## 业务通知与桌面提醒

会议邀请卡片仅携带主题、会议号，入会仍经过密码/等候室检查。预定的创建、修改、取消及会前提醒发给预定者；当前预定模型没有被邀请者列表。会后任务与通知队列同事务提交，事件及收件人规则见[共享记录契约](../server/meeting_ms/api/shared-records-contract.md)。

通知使用稳定 UUID 去重、指数退避重试；取消、改期、过时提醒不补发。投递后删除队列内容，投递元数据保留七天。这是业务投递队列，不是消息归档服务器。通知不含入会密码和等待者资料。

桌面 IM 提醒仅面向仍有成员资格的、服务账号 `openmeeting-meetings` 持有且绑定 `openmeeting_room_id` 的活动会议私有群聊天（文字、图片、视频、语音、文件、位置）。沿用 SDK 的窗口聚焦、聊天可见性、免打扰及声音节流规则。私聊、普通群、会议邀请、好友/群申请和 `notice` 业务消息静默，不产生 IM 桌面提醒或任务栏角标；已结束、已离开、隐藏及免打扰会话不计角标。SDK 自身的登录失效提示仍属于认证错误处理。

`notice` 投递设置 `exclude_from_unread=true` 和 `push.disabled=true`，不增加新未读或离线推送，但内部状态同步与会后结果仍正常投递。桌面使用会议群会话计算角标，不使用包含旧私聊/系统消息的全局未读总数；无需修改历史已读位置。会议聊天阅读、群解散或退出登录后重新计算并清除角标。独立的会前提醒及录音通知设置不属于此 IM 策略。

具体回归命令与原生通知验证范围见[桌面测试说明](../frontend/TESTING.md#音频补丁与会议通知)。

## IM/RTC 需要补齐或配置的问题

| 项目 | 当前证据或限制 | 建议 |
| --- | --- | --- |
| OSS 上传跨域 | Web SDK 上传依赖目标 OSS 的 CORS 配置 | 核对实际应用来源、方法、请求头及下载暴露头；历史失败见[接入记录](meeting-im-development.md)，不推定当前部署仍失败 |
| 屏幕共享 | 当前应用通过 SDK 补丁兼容第二视频轨道，不代表官方屏幕共享能力 | 兼容规则集中维护在[共享设计](im-rtc-second-video.md)，平台正式接口完善后评估替换 |
| 强制媒体控制 | 业务禁麦和客户端开关不能证明服务端强制阻断发布 | 补服务端发布权限、撤权事件、重连后的权限恢复 |
| 媒体统计 | 日用量不是 RTT、丢包、抖动、码率、帧率 | SDK 暴露统一 getStats 或质量事件，现有兼容实现暂留 |
| 置顶、管理他人消息 | 会议主持人不是 IM 群管理员 | 后续增加会议后端鉴权代理并核验消息所属会议；当前实现不开放越权入口 |
| Windows/Web 闭端系统提醒 | 官方文档没有该离线 OS 推送通道 | 保持后台任务运行，重连同步通知；需要闭端推送时另补通道 |
| 文件和消息保留 | 服务商配额、保留期及会议结束生命周期各有影响 | 配置和权限边界见[会议聊天](meeting-im-chat.md#配置与上线边界)，不把平台存储等同于会后聊天归档 |
| 服务账号保留 | 客户端依赖 IM 校验 notice 身份，群由 openmeeting-meetings 持有 | IM 管理端保留这些账号，防止普通注册占用，不向客户端发服务账号票据 |

通知 worker 每 15 秒运行，数据库行锁避免多实例并发重复投递，超时通过 IM 幂等键恢复。运行环境就绪状态需现场验证；部署、迁移和备份按[运维指南](../server/OPERATIONS.md)执行，不在本页维护某次容器状态。

参考：[消息](https://www.syznlink.com/docs/client/web/messages)、[文件](https://www.syznlink.com/docs/client/web/files)、[资料](https://www.syznlink.com/docs/client/web/contacts)、[推送](https://www.syznlink.com/docs/server/push/overview)。当前功能和真实平台边界见[功能状态](feature-status.md)。
