# Flutter 会议与 IM 接入

移动端使用与桌面相同的业务 API；六位会议号、用户身份、预定、房间及会后记录均以服务端为准。功能开关和平台支持决定可用入口，不以原型演示数据或桌面实现推定移动端能力。

## 分层

- `features/live_meeting/domain/`：房间、预定、页面状态和仓储契约。
- `features/live_meeting/data/`：复用 Dio、鉴权 REST 和业务 WS；路径集中在 `core/api/endpoints.dart`。
- `core/im/`：进程内 IM 生命周期、票据引导、消息及媒体资源；SDK 消息缓存与业务会议数据库分开。
- `features/live_meeting/presentation/`：Riverpod 控制器和真实会议页面；组件通过 notifier 执行操作。

## 当前行为

首页提供快速会议、加入、预定及录音转写入口。预定列表以活动场次与会后记录分别表示进行中会议和结果。入会处理密码、等候室、批准、静音及主持人权限。

正式入会后建立并持有 IM 聊天订阅，关闭聊天面板和最小化会议不等于退出会议；离会释放订阅，重入建立新订阅。面板可见性控制已读，不决定是否接收消息。会中聊天、附件和下载使用 IM SDK；业务 WS 仅同步会议状态。

房主客户端按授权音轨采集并上传录音分片；会后处理状态、记录读取和写权限按业务 API 展示。独立录音与导入由服务端转写和总结。

## 鉴权、媒体与恢复

业务 token 保存在安全存储中。业务 API 提供 AppKey、地址和单次 IM/RTC 票据，平台密钥留在服务端。SDK 实例按进程复用，账号变化时释放媒体并退出原身份。

业务 WS 与 RTC 独立维护。SDK 负责媒体连接及续期，客户端不得把每次 reconnecting 当作重新入会。业务失联后获取当前房间快照；权限或会议终态停止重连。

音视频超时显示具体原因，并提供一个重试入口；并发重试被抑制，离会后的迟到结果被忽略。当前遗留问题以[功能状态的连接恢复章节](../docs/feature-status.md#连接恢复)为准，不以提示修复视为媒体连接已修复。
