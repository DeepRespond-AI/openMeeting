# 移动端 UI 布局设计

首页采用白色卡片、蓝色主色和圆角，会中采用深色主题。本文维护首页与会中自适应网格的当前布局；架构、主题、组件及国际化约定见[开发指南](DEVELOPMENT.md)，具体尺寸以代码中的主题配置为准。

- 首页固定为两列四块：快速会议、加入会议、预定会议、录音转写。独立消息功能开关仍控制右上角入口，不挤占四宫格。
- `/recording-tools`，集中展示开始录音与导入音频，分别打开既有 `/recording`、`/import`；原路径与历史页入口保持有效。
- 首页即将开始列表读取既有不限定日期的预定接口，按本地日期分组并排序，展示起止时间、会议号、进行中和已入会状态。已取消/已过期的非活动场次不显示；昨天仍在进行的场次保留。首页不添加全部会议按钮。
- 点击日程主体打开详情，保留加入、房主编辑/取消及原来的活动限制。点击已入会场次直接恢复会中；已有其他会议时保留原会话冲突保护。
- 首页采用与预定列表相同的前台刷新周期，回前台和下拉可刷新。完整预定管理及提醒器的原行为不变。
- `RoomGridLayout` 根据舞台宽高和人数选择行列。少量成员伸展填满舞台；末行有一个空位时由同样大小、可复制邀请信息的框填充。不是简单地为所有奇数人数添加空格：能完整排布时无需邀请补位。
- 舞台不足以容纳多人时保持成员卡片最小高度、独立滚动。`CustomMultiChildLayout` 使用稳定成员标识，人数/行列变化时保留成员组件；共享画面沿用原有区域与接收逻辑。

页面布局与媒体协议、录音策略分别维护。界面与导航验收不能替代摄像头采集、音视频互通及后台录音验收。

检查命令与截图采集方法见[移动端测试说明](TESTING.md#首页与自适应网格)。本文只维护当前布局规则。
