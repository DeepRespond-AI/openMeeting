> 文档类型：开发过程或验收记录。保留当时的设计、环境和执行边界；当前能力以[功能状态](../docs/feature-status.md)为准，不作为当前启动或升级指南。

## 与桌面端一致的行为

| 项目 | 移动端实现 |
|---|---|
| 结束导航 | 主持人结束、成员离开、远端结束或等候室取消后直接首页；关闭已打开弹层，不再显示结束中转页，也不自动打开纪要详情。失败保留房间和错误供重试。桌面同样处理；定向验收（本地产物：`../.artifacts/meeting-return-home/测试报告.md`，需先运行对应脚本生成）与下文历史全流程结论分开记录 |
| 消息入口 | 双环境 `features.standaloneMessages=false`，隐藏首页右上角消息按钮及消息快捷卡；三个会议快捷操作仍使用原主题。桌面 `meeting-ui.json` 的 chat=true，因此会中聊天保留 |
| 开始/停止录音 | 创建会议即遵循后端 active/epoch 自动采集；移除手动开始、停止、申请和审批按钮。旧活动房间仅通过幂等 start 兼容激活，失败显示原因并允许重试，禁止把无音轨视为录音成功 |
| 采集与结束 | 已授权音轨转为 16 kHz 单声道 PCM16，按参会者分片。正常结束与转交主持人前确认最后一段上传；失败保留原状态与重试机会。主持人异常退出未上传的内存分片仍可能丢失 |
| 录音状态 | 保留等待音轨、采集中、上传中、错误及重试。会后显示真实处理状态；模型失败仍能下载已经保存的音频 |
| 会后共享 | 实际参会者（包括提前离开者）读取相同 meetingId 和同一份音频。列表和详情消费 can_manage；等候室未获准身份、未参会账号由后端拒绝 |
| 成员只读 | 隐藏列表滑动删除、标题编辑、重命名、删除、重新转写、处理重试、纪要生成/停止/编辑及生成补充输入；保留读取、复制、分享及音频下载。后端写权限仍为最终依据 |
| 下载与导出 | 通过既有鉴权 Dio 流式下载，完成后才发布文件，取消/失败删除临时文件；录音保存在应用私有目录并按账号隔离。系统分享面板用于另存到文件或分享，导出取消不显示虚假成功 |
| 通知与刷新 | 只接受 notice 发送的 openmeeting.meeting v1 已知事件，过滤撤回/擦除及非法ID，按会话/seq 有界去重。复用真实 SDK，不新增通知数据库；收到后刷新记录并提供查看入口，回到前台也刷新 |
| 提示不遮挡 | 根导航和 Shell 导航分别监听弹窗；弹窗打开时清理旧提示，弹窗期间只刷新数据、不弹出遮挡按钮的会后通知。账号切换和导航也清理残留提示 |
| 独立录音 | 保留原手动麦克风/系统声音、暂停恢复、本地保存、后台上传与转写流程；会议共享不扩大独立录音记录的访问范围 |

## 配置与生命周期

`can_manage` 缺省为 true，兼容旧版只返回所属记录的后端；新版服务返回明确权限。不能据此绕过服务端授权。元数据、转写、纪要及处理状态订阅当前账号；下载在账号改变或 provider 销毁时取消，避免复用上一账号界面和资源。

本轮新增配置：`features.standaloneMessages`、`live.noticeDedupLimit`；录音分片、队列、无帧检测沿用前一轮双环境参数。文案只编辑 live_meeting ARB fragments，提交时保留生成代码。

## 验证与边界

验收源代码与复现方法见 [E2E 说明](../tests/e2e/mobile-auto-records/README.md)。本地产物 `.artifacts/mobile-auto-records/`，`测试报告.md` 从结构化步骤、日志、预算和逐图检查记录生成，APK、凭证与缓存不进入 Git。此前 `.artifacts/mobile-desktop-parity/` 对应手动录制旧基线，不能作为本轮自动录音验收。

完整回归覆盖预定、会中设置、等候室、保留的会中聊天、自动录音状态、结束、早退成员记录、只读及下载，分别验证真实 API、真实 IM 通知和 Flutter 双视口页面。独立录音、导入、个人设置另有页面入口冒烟；原生录制、文件选择和导出不能用入口冒烟替代。

无线平板本轮探测为 offline；没有覆盖原应用或登录态。Flutter VM 适配安全存储、平台宿主、麦克风可用性与播放器，合成 PCM 注入真实后端，不代表硬件采集/播放通过。Android 编译、真机执行和 iOS 分别记录。真实 STT/LLM、多人音画质量、权限恢复、原生导出/导入、后台和长会仍需设备与模型验收。

本轮最终验收结论为 API 降级：完整页面轮次曾通过116步，但后续复跑出现消息更新超时，累计30分钟后不再重跑业务E2E。已修复快照先发送、后订阅广播的竞争窗口，修复后241项单元/组件及Android构建通过；没有最终E2E复验，不能认定全部功能无问题。报告保留历史通过、最新失败、采集不足及纯组件补拍的不同范围。

移动独立屏幕共享、完整发言人/网络指标、后台推送和系统来电不属于已完成能力；本轮与桌面一致的是录音策略、共享记录权限及相关界面。
