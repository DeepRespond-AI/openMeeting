# 当前功能状态与验收边界

本文描述 develop 的实现范围，不记录逐次提交、旧版本差异或历史通过数。操作入口见[文档导航](README.md)，接口以[API 契约](../server/API.md)为准。运行环境是否就绪需现场检查，代码存在不等于真实设备、平台或生产包已验收。

## 会议与记录

| 能力 | 当前实现 | 限制与验证重点 |
|---|---|---|
| 预定会议 | 固定六位会议号，支持房主开始、重复场次、编辑与取消 | activeRoomId 表示当前场次，meetingId 表示会后记录 |
| 入会与控制 | 密码、等候室、批准入会、主持人操作、静音和举手 | 账号权限、跨设备冲突及重复入会需分别验证 |
| 会中聊天 | IM 专属群、附件、姓名头像、媒体预览、未读及消息订阅 | IM/存储错误需独立处理；不以聊天可用推断媒体已连接 |
| 音视频 | 通过 IM RTC SDK 连接，采集与播放由客户端负责 | 实际摄像头、麦克风、输出设备、拒绝与恢复需真机验证 |
| 桌面共享 | 使用 RTC 中独立视频发布与业务共享归属 | 公网网络、系统选屏、容量及各平台分别验收 |
| 自动录音 | 房主采集授权音轨，PCM 分片仅保存 MinIO / OSS，数据库保存索引；会后合成、转写和总结，成功后延迟清理 | 依赖对象存储；本次升级清理旧数据库分片，新失败任务保留源分片；未采集或未确认上传的音频无法保证恢复；不提供会议视频文件录制 |
| 会后记录 | 实际参会账号可读取，所属账号拥有修改及重处理权限 | 音频需主动下载；录音、转写和总结状态分别展示 |
| 独立录音与导入 | 客户端采集或上传文件，服务端执行转写与总结 | 依赖 STT/LLM 就绪，不承诺离线本地推理 |

## 连接恢复

- 业务 WS 与 SDK 媒体连接独立维护。重连取得当前房间快照；同账号其他有效连接不能被延迟清理误删。
- 最后一条有效 WS 确认断开后，默认保留 3 秒重连窗口，每秒扫描。普通成员到期清退，主持人到期结束会议；没有即时断连信号时仍依赖心跳超时。
- 桌面端提供当前会议中本人 leaving 会话的显式释放与重试；只有平台确认释放才申请新票据。平台清理能力及按账号移出的竞争窗口是现有约束。
- 移动端对齐桌面端的后台释放队列：离会和新业务房间创建不等待媒体清理，只有新 RTC 接入等待旧请求和本端媒体释放；平台 leaving 状态按配置等待，超时后可重试。控制器与页面夹具回归覆盖快速退房重入，不等于真实 RTC 平台释放耗时或 Android/iOS 真机已验收。见[当前功能与限制](feature-status.md)。
- 移动端首次入会统一显示初始化页，业务信令与 RTC 就绪后进入正常会议，进入后不再展示后台连接提示。已进入会议后的媒体重试保留会议内容；初始化超时或失败可重试、离会。业务切房仍不等待旧媒体释放。见[当前功能与限制](feature-status.md)。

连接策略见[生命周期说明](meeting-resilience.md)，桌面恢复的接口边界见[当前功能与限制](feature-status.md)。

## 客户端与管理端

桌面端支持会议模块配置、IM 工作台、资料设置和更新。Flutter 支持首页会议入口、预定、会中聊天、记录读取、录音/导入及应用更新；平台配置和功能开关决定可见入口。移动端屏幕共享、完整统计、后台通话、推送和 iOS 行为不能按桌面能力直接推定，需按源码及目标平台单独验收。

管理端提供用户与会话、短信、服务状态、STT 模型、LLM、存储及客户端版本发布。服务端经统一网关提供业务与管理接口。管理端安装包、桌面与移动端完整录音及导入文件支持授权后直传 OSS / MinIO；本地存储保留原上传路径。会中分片与实时转写仍经业务服务。直传已完成隔离 MinIO / PostgreSQL、浏览器真实上传下载及两端传输契约测试；生产 OSS CORS、原生设备与大文件网络环境尚需目标部署验收。

对象存储支持通过环境变量选择本地卷、Docker MinIO 或阿里云 OSS，会议录音和版本安装包共用配置；多人会议合成录音也已接入。切换只影响新写入，旧文件按记录的后端读取，配置和数据需保留。MinIO 已完成真实容器、API、管理端和具名卷持久化验收；阿里云真实连接及原生设备播放仍需在目标环境验证。说明及验收入口见[对象存储指南](object-storage.md)。

## 部署与已知限制

- meeting_ms 使用进程内房间广播，按单实例部署；多副本信令需要额外实现。
- 服务使用各自 PostgreSQL 实例；schema 由 Alembic 管理。正常启动按配置执行结构更新，数据卷不随代码更新删除。
- 供应商 HTTP 出站走网关代理；模型仓库及 CDN 必须在实际域名白名单中。客户端 RTC 媒体网络与后端 HTTP 代理分别排查。
- STT/LLM 不就绪时保留可用音频和结果，不能把任务受理当成处理完成。

## 待验收范围

物理设备音画质量、权限恢复、长会与弱网、生产安装包、系统通知与后台行为、各桌面平台和 iOS 需要独立验收。组件夹具、合成输入、构建成功和单个平台的结果不能替代这些检查。测试方法见[测试入口](testing/README.md)。
